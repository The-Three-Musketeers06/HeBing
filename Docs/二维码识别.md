# 二维码识别

“二维码识别”（`Basic 2D Code Reader`）现在由本地 ZXingCpp 解码，支持 QRCode 和 ECC200 DataMatrix，运行时不需要联网、VisionPro 或 VisionMaster。当前范围是读取码内编码内容；标签旁的 Lot、Date 等印刷文字不参与识别。

## 使用步骤

1. 启动 `bin/Release/net10.0-windows/AiVisionStudio.exe`。
2. 在流程中添加图像加载工具，选择 `D:\Project\Images` 中的 BMP、PNG、JPEG 等图像，把输出设为 IM0，运行后确认预览中有图像。相机采图等上游步骤也可以提供输入。
3. 添加并打开“二维码识别”，输入图像选择 0。已有流程直接打开对应工具即可。
4. 读取整张图时关闭“使用区域参数”。需要限定范围时，选择“图形类型”，开启“使用区域参数”，点击“区域”旁的“手动画选…”，选择矩形、圆形、扇形、圆环或多边形等形状，在图像上画出范围并应用。应保留完整码和码周围空白边界。图像掩膜模式使用指定 IM 中非零像素作为读取范围。
5. 解码类型先选“自动”；也可单独选择 QRCode 或 DataMatrix。码形状用于筛选 DataMatrix 的正方形或矩形，选择“自动”可同时读取两种。QR 码不受 DM 形状筛选影响。
6. 设置“最大读取数量（0为不限）”：0 返回区域内能够解出的全部码；1 只返回一个，其他正整数返回不超过该数量的码。不同位置的相同内容分别计数。结果按本轮检出的原图位置从上到下、从左到右排列；启用上限时达到数量即可结束后续增强尝试。
7. 初次使用建议保持：最小单元宽度 -1、模块数“自适应”、点阵类型“普通图像”、腐蚀次数 0、打印质量类型“无”。黑字白底用“白底黑码”；反色用“黑底白码”；“Both”会尝试两种极性。超时时间默认 2000 毫秒，0 表示不设超时。
8. 点击“测试”。成功时图像上显示编号、内容摘要和码的四边形位置；“输出参数”中查看完整内容和数量。已有工程如果关闭了“文本显示”或“结果区域”，手动开启后再测试。
9. 点击“保存”保存工具参数。无需训练二维码模板。

## 输出及绑定

| 输出 | 含义 |
| --- | --- |
| `Result` | 本次是否至少成功解出一个码 |
| `Code Count` | 本次返回数量 |
| `Content` | 各码的完整内容，按行连接；内容本身也可能含换行 |
| `Codes` | 每个码的明细数组；多码程序处理应优先使用此数组 |
| `Codes[i].Content` / `Code Type` | 第 i 个码的内容及 QRCode / DataMatrix 码制，索引从 0 开始 |
| `Codes[i].Raw Bytes Base64` | 解码后的原始内容字节，以 Base64 无损输出 |
| `Codes[i].Corners` | 四个角点，使用原始输入图像的像素坐标 |
| `Codes[i].Module Rows` / `Module Columns` | 解码得到的模块行、列数 |
| `Codes[i].Angle` / `Mirrored` / `Inverted` | 方向、镜像及反色信息 |
| `Limit Reached` | 已达到设置的返回数量，不表示一定还有额外的码 |
| `Elapsed Time` | 解码耗时，单位毫秒 |
| `Message` | 失败原因；未解出时不会用附近文字替代 |

可通过现有绑定按钮选择 `Codes` 数组项的 `Content` 给后续工具使用。失败时引擎清理上次成功的绑定结果及图形，仅发布本次状态；不能继续使用上次的码内容。超时也不返回部分结果。

## 参数及当前限制

- 最小单元宽度、指定模块数和 DM 码形状用于过滤解码结果；-1 或“自适应”不限制对应条件。模块宽度单位为输入图像像素。
- 腐蚀在归一化灰度图上执行，会改变条纹宽度。先用 0；仅在确有需要时调整。
- 读取区域可通过现有“绑定模板定位…”跟随形状匹配的位置变化。二维码本身不需要训练。
- 本次实现基础“二维码识别”。一维“条码识别”、高级二维码工具、点阵专用模式和打印质量分级不属于本次范围。选择后两种未支持模式时会明确报错。
- 超时和取消在原生调用前后及各轮处理之间检查；正在执行的单次原生解码不能强行中断，实际返回时间可能晚于设置值。
- 每次原生调用最多读取 255 个码；“不限”会通过多轮空间排除继续读取，不按内容去重。
- 图像截图和放大显示不会增加原始细节。模糊、缺损、码制不受支持的图像仍可能无法解码。
