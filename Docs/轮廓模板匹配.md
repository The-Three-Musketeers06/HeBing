# 轮廓模板匹配

采用软件自有轮廓匹配引擎，独立运行。支持平面目标的位置、旋转和等比缩放定位。

## 建立模板

1. 加载或采集输入图像，打开“形状模板匹配”。
2. 在“模板示教”页面点击“创建”，打开白色系“模板配置”弹窗。可选择当前输入图像，也可选择其他图像。重新选图只清空弹窗中的区域、屏蔽和原点草稿，工程中的原模板和搜索设置保持不变。
3. 使用画布上方工具栏选择矩形、圆形或多边形；右键矩形按钮还可选择扇形和圆环。拖动控制点调整大小或方向。选好区域后可直接点击底部“训练”，无需额外点击“应用”；画布内不显示浮动提示栏。
4. 用画笔屏蔽排除背景、反光和无关特征；用橡皮擦恢复特征。开启“全部屏蔽”后，可用橡皮擦只保留需要的轮廓。右键画笔可设置半径，右键橡皮擦可清除全部屏蔽。支持撤销、重做、缩放、原始比例和适应窗口。
5. 右侧配置尺度模式、特征尺度、阈值模式和对比度阈值。手动特征尺度对应 1～10 层特征金字塔；自动模式根据区域大小确定层数。匹配中心可在底部输入，也可通过工具栏拖动十字和方向柄；开启“锁定”后不可编辑中心。
6. 点击底部“训练”，成功后模板直接更新到工程，右侧列表显示模板的特征数、轮廓数、尺寸和中心。训练失败、取消训练或关闭弹窗均保留已保存的模板；未训练的草稿不会写入工程。训练完成后可关闭弹窗，切换到运行参数点击“测试”。

模板保存在工程内，包含区域、屏蔽、轮廓和原点。“模板存图”开启时同时内嵌完整训练图像，关闭时保留算法所需的裁剪图像。使用主窗口保存工程，重新打开工程时自动恢复，无需单独保存或加载模板文件。修改区域或示教参数后，需要重新训练。旧工程已经关联的模板文件仍兼容。

## 运行匹配

默认按全图搜索，无需点击额外的搜索按钮。在“运行参数”页面设置角度、尺度、分数和目标数量，点击底部“测试”。需要局部搜索时，可开启“使用搜索区域”，在搜索区域参数中手动画选；区域应覆盖目标参与匹配的全部轮廓。

- 默认角度为 -180°～180°，默认尺度为 1～1，默认超时为 3000 毫秒。
- 存在尺寸变化时，需要在建模设置与运行设置中都允许相应尺度范围。
- 尽量按实际工况缩小搜索区域、角度与尺度范围。超时时会明确报告，并清空未完成的匹配结果。
- “使用极性”要求边缘明暗方向与模板一致；忽略全局极性允许整体反色，忽略局部极性允许各段边缘独立反色。
- “匹配结果”页面展示 X、Y、角度、尺度、分数与耗时；右侧显示匹配轮廓。

当前定位模型使用平移、旋转和等比缩放。实际工件的识别率、误检率、精度和处理时间，应使用现场图像验证。

## 画选与平移

需要区域输入的参数组提供“手动画选”入口，并按算子声明的类型提供图形。支持单区域和区域数组。

- Enter 应用当前画选；Esc 取消当前画选；Delete 清除草稿后重画。
- 多边形逐点点击，双击结束；Backspace 撤回顶点。
- 拖动区域中心移动，拖动控制点调整。应用后同步写入参数，并支持撤销、重做。
- 手形按钮用于拖动画面。绘制期间中键也可平移，滚轮缩放。
- 轮廓窗口按实际 X/Z 坐标画选。点云区域在参考坐标系 XY 俯视图中画选，长方体、圆柱等区域的深度取框内点云范围；有向包围盒可绕 Z 旋转。

## 让检测区域跟随工件

在模板匹配之后的二维检测工具中，点击“绑定模板定位”，选择前面的形状模板匹配工具。系统同时关联模板基准位姿和匹配运行位姿，并开启位置修正。

图形编辑会在当前图像位置显示区域，并逆变换后保存到示教坐标，避免运行时重复平移、旋转。定位工具需要先成功运行，才能获取可用的运行位姿。
